# 🐚 เรียน Bash Script จากศูนย์

คอร์สพื้นฐานสำหรับเริ่มต้นเขียน Bash Script บน macOS โดยเรียงจากง่ายไปยาก
ทุกไฟล์มีคอมเมนต์ภาษาไทยอธิบาย และรันได้จริงทุกไฟล์

## 📚 ลำดับการเรียน

| ลำดับ | ไฟล์ | หัวข้อ | สิ่งที่จะได้เรียน |
|-------|------|--------|------------------|
| 1 | `01_hello.sh` | เริ่มต้น | shebang, echo, comment |
| 2 | `02_variables.sh` | ตัวแปร | การประกาศ, การใส่ quotes, command substitution |
| 3 | `03_input.sh` | รับค่า | `read`, arguments ($1, $2, $@) |
| 4 | `04_condition.sh` | เงื่อนไข | if/elif/else, การเปรียบเทียบตัวเลข/ข้อความ/ไฟล์ |
| 4.5 | `04-1_condition.sh` | โจทย์ฝึกต่อยอด | flags ตรวจไฟล์/ข้อความทั้งชุด (โจทย์ล้วน 10 ข้อ ห้ามใช้ loop) |
| 5 | `05_loops.sh` | วนซ้ำ | for, while, until |
| 6 | `06_functions.sh` | ฟังก์ชัน | สร้างฟังก์ชัน, ค่าที่รีเทิร์น, local variable |
| 7 | `07_arrays.sh` | อาเรย์ | indexed array และการวนลูป |
| 8 | `08_backup.sh` | โปรเจกต์จริง | รวมทุกอย่างเป็นสคริปต์ backup ไฟล์ |

## ▶️ วิธีรันสคริปต์

### วิธีที่ 1: ใช้ bash รันตรง ๆ (ง่ายสุด ตอนเริ่มเรียน)

```bash
bash 01_hello.sh
```

### วิธีที่ 2: ทำให้ไฟล์รันได้เอง (แบบที่คนใช้งานจริง)

```bash
chmod +x 01_hello.sh    # ให้สิทธิ์ "executable" ครั้งเดียวพอ
./01_hello.sh           # รันด้วย ./ ข้างหน้า
```

> เครื่องนี้ผม chmod +x ให้ทุกไฟล์แล้ว ลองรันแบบวิธีที่ 2 ได้เลย

## 🛠️ ตั้งค่า VSCode (แนะนำ)

1. ติดตั้ง Extension: **Bash IDE** (มี lint ช่วยเช็ค error ก่อนรัน) หรือ **ShellCheck**
2. เปิด Terminal ใน VSCode: กด `` Ctrl + ` `` (backtick) แล้วรันสคริปต์ได้เลย
3. ถ้าอยากดู error ชัด ๆ ตอนหัดเขียน ให้รันแบบนี้:

```bash
bash -x 02_variables.sh   # จะเห็นทีละบรรทัดว่า bash ทำอะไร
```

## 🐞 คู่มือ Debug (ฉุกเฉินใช้ได้ทุกไฟล์)

| เครื่องมือ | ใช้เมื่อ | ตัวอย่าง |
|-----------|---------|---------|
| `bash -x ไฟล์.sh` | อยากเห็น bash ทำงานทีละบรรทัด (ค่าตัวแปรโชว์หลังแทนค่าแล้ว) | `[ bash123 = 'bash123]'` ← เห็นบั๊กเว้นวรรคชัด ๆ |
| `set -x` / `set +x` | อยาก trace แค่บางช่วงของสคริปต์ ใส่ไว้หน้า-หลังโค้ดช่วงนั้น | คู่กันเหมือนเปิด-ปิดไฟฉาก |
| `set -u` | จับตัวแปรที่ไม่มีอยู่จริง (พิมพ์ชื่อผิด) — พังทันทีพร้อมบอกชื่อตัวแปร | `oragne: unbound variable` |
| `set -e` | อยากให้หยุดทันทีที่คำสั่งไหนล้มเหลว ไม่ไหลต่อ | ใส่ไว้บรรทัดแรกหลัง shebang |
| `echo "$var"` | ง่ายสุด — พิมพ์ค่าตัวแปรออกมาดูตรงจุดสงสัย | ลบทิ้งตอนเสร็จ |
| `$?` | เช็คว่าคำสั่งก่อนหน้าสำเร็จไหม (0 = สำเร็จ) | `echo "exit: $?"` |

เคล็ดลับอ่าน error:
- `บรรทัดที่ bash ฟ้อง` = จุดที่มัน *ระเบิด* ไม่ใช่จุดที่บั๊กอยู่เสมอไป — มอง**ขึ้นไปข้างบน**ด้วย
- ผล trace ภาษาไทยที่เป็น `$'ส\231...'` ตัวเพี้ยน ๆ = ของตกแต่งจาก `bash -x` เท่านั้น โปรแกรมทำงานปกติ อ่านข้ามได้
- ติดตั้ง **ShellCheck** ไว้ตรวจโค้ดก่อนรัน (จับบั๊กเว้นวรรค/ชื่อตัวแปรผิดได้หมด):
  `brew install shellcheck` แล้วรัน `shellcheck ไฟล์.sh` + ติด VSCode extension "ShellCheck" จะขีดเส้นแดงให้ตอนพิมพ์

## 📝 หมายเหตุเกี่ยวกับเครื่อง Mac เครื่องนี้

- Terminal ปกติใช้ **zsh** แต่ไม่กระทบ เพราะทุกสคริปต์มี `#!/bin/bash` ที่บรรทัดแรก
  ซึ่งบอกให้รันด้วย bash เสมอ
- bash บนเครื่องเป็นเวอร์ชัน 3.2 (Apple ติดตั้งมาให้) — สำหรับพื้นฐานทั้งหมดในคอร์สนี้เพียงพอ
  แต่ฟีเจอร์ใหม่อย่าง associative array (`declare -A`) จะใช้ไม่ได้จนกว่าจะติดตั้ง bash ใหม่ผ่าน Homebrew

## 🎯 แนวทางการเรียน

1. เปิดไฟล์ใน VSCode อ่านคอมเมนต์ทีละส่วน
2. รันสคริปต์ แล้วเทียบ output กับโค้ด
3. **แก้โค้ดเล่นดู** — ลองเปลี่ยนค่า เพิ่มบรรทัด ดูว่าเกิดอะไรขึ้น (พังได้ ไม่เป็นไร)
4. ทำแบบฝึกหัดท้ายไฟล์ (อยู่ในคอมเมนต์)
