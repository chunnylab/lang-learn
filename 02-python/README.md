# เฟส 2: Python สำหรับ Cloud และ DevOps

โฟกัสเฉพาะแกนหลักของ Python ที่ใช้ในงาน Automation, Cloud (AWS/Cloudflare) และสัมภาษณ์งานสาย DevOps/SysAdmin

## หัวข้อที่จะสร้างในเฟสนี้

1. `01_core.py`: ตัวแปร, `list`, `dict`, `set`, `if`, `for`, `def`, `None`
2. `02_files_json_yaml.py`: `pathlib`, อ่าน/เขียนไฟล์, `json`, `yaml`, `csv`, Regex พื้นฐาน
3. `03_errors_logging.py`: `try/except`, `raise`, `logging`
4. `04_subprocess_http.py`: รันคำสั่ง Linux จาก Python, ยิง HTTP API, อ่าน Environment Variable
5. `05_cli_and_pytest/`: ทำ CLI ด้วย `argparse` และเขียน Unit Test ด้วย `pytest`
6. `06_aws_boto3/`: สคริปต์ตรวจ Resource บน AWS (เช่น EC2 ที่เปิดค้างไว้ หรือ S3 Bucket)
7. `07_project/`: โปรเจคจบเฟส 2 (Cloud Resource Checker พร้อม Test และ GitHub Actions)
